## 不限制的含义

安装和后台共用配置表单：`Max Tokens = 0` 表示网站不发送 `max_tokens`（Gemini 不发送 `maxOutputTokens`）；正数表示显式额度。接口或模型自身仍有输出和上下文上限。推理模型的 completion tokens 包含推理消耗，因此只缩短可见文本不能保证12000额度总够用。

这是小规模试验，说明最终方案在所测主题上可用，不能保证所有主题、请求或接口默认额度都成功。模型响应存在随机性；仍保留服务端严格校验和明确失败提示。
