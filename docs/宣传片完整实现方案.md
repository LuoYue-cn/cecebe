# 测测be产品宣传片完整实现方案

> 主题：给好奇，一点答案  
> 主版本：40～45 秒竖屏产品宣传片，以 45 秒为制作基准  
> 画幅：1080 × 1920，9:16  
> 内容：中文旁白、背景音乐、音效、屏幕文案及字幕  
> 品牌：测测be · 好奇有答案  
> 网站：https://ccb.h666h.com  
> 本方案仅制作完整宣传片，不制作 15 秒短版。

## 1. 项目目标与创意

围绕一个简单、完整的过程展开：输入好奇的问题，生成测试，完成回答，看到属于自己的结果，最后邀请朋友一起探索。

宣传片需要让观众理解三个信息：

1. 有一个好奇的问题，就可以在测测be发起测试。
2. 网站既支持知识测试，也支持性格、兴趣、关系与偏好探索。
3. 结果可以提供倾向类型、核心特征与探索建议，并支持分享。

期望的苹果宣传片质感，通过克制的画面、清晰的文字、连贯的运动和精细的声音实现。沿用网站的奶油白和紫色，让观众看完视频再进入网站时，感到视觉和产品是一致的。

镜头围绕产品本身展开。界面卡片像轻薄的物体悬浮在柔和空间中，输入框、生成按钮、题目和结果之间通过形态变化连接。全片以连续运动建立质感，重点表现“从输入框变成题目卡片”和“从题目卡片展开成结果页”两次核心转场。

## 3. 视觉方向

### 3.1 奶油白空间，紫色作为主角

画面大部分时间保持明亮、干净。网站界面像一张轻薄的卡片悬浮在空间里，用柔和光影增加层次，少量浅绿点缀结果页面，延续网站“好奇游乐场”的气质。

| 用途 | 建议颜色 | 使用方式 |
| --- | --- | --- |
| 主背景 | 奶油白 `#F8F5ED` | 贯穿全片，舒服、温暖 |
| 品牌主色 | 紫色 `#7132C5` | 关键词、生成按钮、品牌标志 |
| 过渡底色 | 浅薰衣草 `#EEE4FA` | 卡片背景、柔和光晕 |
| 辅助色 | 淡薄荷绿 `#E7F3E8` | 结果中的建议、探索与成长 |
| 主要文字 | 深紫灰 `#30283D` | 标题、正文，保证对比度 |

整体约为 75% 奶油白、15% 紫色系、10% 其他颜色。这是视觉分配目标，不需要逐帧机械计算。紫色集中出现在重要动作和文字上，避免整屏过亮、过艳。背景可加入非常轻的渐变，让它像有光照的纸面。

### 3.2 排版与构图

- 全片最多同时出现一个主标题、一张主卡片、两三个辅助元素。
- 主体按竖屏设计，保持足够大；复杂界面使用真实内容的重点摘录。
- 主标题建议 76～100 px，重点结果类型 60～76 px，界面正文 34～44 px，字幕 40～46 px；以导出后手机观看效果为准。
- 中文选用具有可用授权的清晰无衬线字体，例如思源黑体或 Noto Sans CJK，明确记录实际字体及授权。
- 字重以常规、中等、半粗为主。大标题整体入场，不做逐字跳动。
- 卡片圆角建议 36～48 px，边框细而淡，阴影柔和、低对比。
- 起始安全区建议：左右各 90 px，顶部 150 px，底部 260 px。平台遮挡范围可能不同，交付前按目标平台预览再调整。
- 重要域名、结果类型和字幕应处于安全区内；装饰可以延伸至边缘。

### 3.3 产品内容真实性

提取现有网站 Logo、配色、组件形态与界面文案。通过可控的界面重绘呈现产品，并与真实页面核对。使用专门的演示数据，不展示真实用户资料、管理后台、密钥、邮箱或私人测试内容。

生成等待过程允许通过动画压缩。画面不添加“瞬间完成”等速度承诺，避免把压缩演示理解为实际响应时间。

## 4. 完整分镜与时间轴

以下以 45 秒为基准。完整旁白生成后允许小幅调整镜头时间，最终保持在 40～45 秒内，并保留至少 3 秒稳定片尾。

| 时间 | 画面与运动 | 屏幕文案 | 声音安排 |
| --- | --- | --- | --- |
| 0～4 秒 | 奶油白背景中央出现小小的紫色光点，缓缓展开成输入光标，第一行文字像思考一样浮现。 | **今天，你好奇什么？** | 柔和氛围音起，轻微提示音；旁白提出问题。 |
| 4～10 秒 | 三个问题依次进入，每次只突出一个，其余轻轻淡出。最后一个问题平滑落进网站输入框，镜头自然靠近。 | 「我的中国历史知识怎么样？」／「我更适合怎样的相处方式？」／「我喜欢什么样的生活？」 | 旁白“关于知识，关于关系，也关于自己。”音乐开始出现轻节拍。 |
| 10～16 秒 | 输入框与紫色按钮成为中心。点击“AI 生成测试”，按钮中的光点向外展开，变成一张张题目卡片，压缩生成等待过程。 | **把一个问题，变成一次探索。** | 点击音，轻柔展开音；旁白读出主题句。 |
| 16～23 秒 | 三张题目卡片连续滑动，选项轻轻点亮，进度向前推进。镜头跟随卡片运动，保持同一个视觉方向。 | **认真回答。慢慢发现。** | 两三个克制的选中音；旁白后留短暂停顿。 |
| 23～32 秒 | 最后一张答题卡片平滑展开为结果页。先呈现倾向类型，再依次出现核心特征与探索建议，留足阅读时间。 | **看见你的倾向。**／**也看见更多可能。** | 音乐变得温暖，加入轻柔和声音色；旁白对应结果信息。 |
| 32～38 秒 | 结果页收拢成适合手机查看的分享长图，顶部二维码清晰可见。两张朋友卡片轻轻进入，形成分享感。 | **把这份发现，分享给朋友。** | 轻微滑动音；旁白发出分享邀请。 |
| 38～45 秒 | 卡片缓缓退场，紫色品牌标志与“测测be”居中，域名出现。最后至少 3 秒主体保持稳定。 | **测测be · 好奇有答案**；**ccb.h666h.com**；「来测测，发现不一样的自己。」 | 品牌旁白与柔和延音收尾，音乐自然淡出。 |

### 4.1 问题与题目设计

三个开场问题用来展示不同用途，不要求在一份测试中混合三个主题。进入答题后，集中展示同一份偏好测试，保证题目、答案与结果之间连贯。

候选题目用于演示，正式制作前应与实际生成的测试内容核对：

1. 空闲的一天，你更想怎样度过？
2. 与朋友相处时，你更看重什么？
3. 面对新的计划，你通常会怎么做？

每张卡片以两到四个简洁选项为主。只让观众看清一次选择与一次进度推进，不在短镜头里塞入完整答题过程。

### 4.2 结果展示

结果选用性格或兴趣偏好测试，突出倾向类型和简短解释。示意内容：

> **温柔回应 · 自然相处型**  
> 你更看重真诚的回应，也喜欢自在、有空间的相处方式。

核心特征可使用“真诚回应”“自然相处”“保留空间”。探索建议可以是“试着说出自己的期待，也为彼此保留自在的空间”。正式内容以经过核对的演示报告为准。

偏好测试画面不展示总分、百分制优劣、正确率或容易被误认为评分的进度条。知识测试的问题在开场出现即可，体现产品用途广度。

### 4.3 分享与二维码

分享长图顶部依次呈现品牌、二维码及“扫码测同款”，再展示测试标题和结果内容。二维码使用公开、可访问的链接，最终渲染后验证识别与落地页。

若二维码用于“测同款”，必须指向已发布的测试；若采用首页链接，文案改为“扫码开启探索”，保持二维码用途与文案一致。

## 5. 动画与转场实现

### 5.1 运动原则

所有主要动画采用“轻轻启动 → 平滑移动 → 缓缓停下”的节奏。卡片旋转控制在很小的角度，阴影柔和，镜头推进保持轻微。

| 动作 | 建议时长 | 参数与表现 |
| --- | --- | --- |
| 按钮点击、选项亮起 | 0.25～0.4 秒 | 微缩放、颜色与阴影变化，反馈清楚 |
| 文字与卡片入场 | 0.6～0.9 秒 | 整体淡入和少量位移，依次错开 0.08～0.15 秒 |
| 核心形态转场 | 1～1.4 秒 | 保持视觉锚点连续，尺寸、位置、圆角联动 |
| 轻微镜头推进 | 2～4 秒 | 小幅缩放，保证文字始终清晰 |
| 结果与品牌收尾 | 稳定停留 | 留出阅读时间，减少持续装饰运动 |

位移和形态变化可先采用 `cubic-bezier(0.22, 1, 0.36, 1)` 一类平滑缓动，再按实际镜头调整。悬浮卡片旋转建议在 ±2° 内；避免明显弹跳和过冲。

### 5.2 三个核心连接

1. **问题进入输入框：** 开场问题和输入框共享位置锚点，文字落位后边框与按钮逐步出现。
2. **生成按钮变成题目卡片：** 紫色高亮区域扩展，轮廓从按钮变为卡片，标题与选项依次出现。
3. **题目卡片展开为结果报告：** 保留卡片中心与边缘轮廓，内部内容交替淡入淡出，倾向类型先出现，建议随后出现。

全片统一主要运动方向，以向上推进为主。少量侧向运动用于展示朋友分享卡片，避免镜头连续改变方向。

### 5.3 手机阅读

不直接缩小整张桌面截图塞进竖屏。对输入、题目、结果重点区域进行适配布局，简化与镜头无关的导航和细节。所有简化后的内容都要与真实产品对应。

## 6. 中文旁白与字幕

### 6.1 声音方向

采用温暖、清晰、克制的普通话声音，语速稍慢，停顿自然。开场像轻轻发问，结果段略微展开情绪，品牌收尾简洁。

先生成两版短试音：一版偏柔和，一版偏清爽。默认倾向柔和、中性、亲切的声音；确定后全片保持同一说话人，不模仿名人或特定品牌广告人物。

### 6.2 完整旁白稿

> 今天，你好奇什么？  
> 关于知识，关于关系，也关于自己。  
> 把一个问题，变成一次探索。  
> 认真回答，慢慢发现。  
> 看见你的倾向，也看见更多可能。  
> 把这份发现，分享给朋友。  
> 测测be。给好奇，一点答案。

片尾“测测be”的具体读法在试音时确认。字幕与标志保留原品牌拼写，语音生成文本可单独标注发音。

### 6.3 旁白制作流程

1. 检查本机或已授权服务可用的中文语音能力、音色、使用条件和输出格式。
2. 使用开场、结果句和品牌句生成短试音，检查发音与情绪。
3. 选定音色后分句生成旁白，保留原始音频。
4. 调整停顿与时间安排，优先重新生成语速不合适的句子；仅在不会明显影响自然度时进行轻微音频时长调整。
5. 按实际语音长度锁定镜头，避免强行把长句挤进既定时间。
6. 输出旁白独立 WAV，以及准确的字幕时间轴。

旁白需要外部付费服务时，先明确可用服务与费用；画面、脚本与样片素材准备可以继续推进。

### 6.4 字幕

字幕与旁白一致，以一行或两行短句呈现。采用深紫灰文字搭配浅色背景，必要时加轻微底色保证对比度。字幕避开主要界面内容和平台遮挡区域。

屏幕主文案与字幕重复时，可在同一安全位置承担字幕功能，避免同一句话同时出现两份。即使静音播放，观众也能理解完整过程。

## 7. 音乐、音效与混音

### 7.1 背景音乐

采用轻盈的电子氛围音乐：柔和合成器、少量钢琴音色、很轻的节拍。前半段带一点好奇感，结果展开时旋律变得温暖，结尾落在干净的延音上。

优先使用原创或具有明确网络发布授权的音乐。保存来源、许可证及必要署名信息。音乐选型以不干扰旁白为前提，不使用无法确认授权的商业歌曲。

### 7.2 音效

点击、选中、卡片展开各配一个轻微声音，与动作准确对齐。关键镜头使用音效即可，不给每个元素变化都加声音。

可使用自制的短音、轻柔气流和低音量提示音，保持音色统一。避免突兀的重低音和响亮转场音。

### 7.3 混音与技术目标

- 音频工程建议 48 kHz，保留高质量原始文件。
- 旁白始终清晰，音乐在说话时适度降低，句间自然恢复。
- 成片响度可从约 −16 LUFS 综合响度开始试听调整，真峰值控制在 −1 dBTP 以下。
- 使用手机扬声器与耳机分别试听，检查辅音、音量变化和底噪。
- 品牌收尾后音乐自然淡出，避免突然截断。

## 8. 技术路线与工程结构

### 8.1 推荐路线

以可控的网页界面动画和逐帧渲染为主，配合 FFmpeg 合成音频与最终编码。优先评估 React/Remotion 类工作流是否适合当前本机环境；若不可用，使用独立 HTML/SVG/Canvas 场景及可确定时间轴的渲染方式。

最终技术选择以本机检查结果为准。先验证一段短片能稳定渲染、字体正确、音画同步，再投入全片制作。

动画工程独立放置，不改动线上网站运行逻辑。制作阶段不需要重新部署网站。

### 8.2 建议目录

```text
promo/
  README.md                 # 环境、制作与渲染说明
  script/                   # 分镜、旁白稿和时间轴
  assets/
    brand/                  # Logo、图标和品牌素材
    fonts/                  # 字体及授权说明
    audio/
      voice/                # 试音、原始分句、完整旁白
      music/                # 音乐与授权说明
      sfx/                  # 音效与来源说明
    data/                   # 演示测试与报告数据
  src/
    scenes/                 # 七个主要场景
    components/             # 卡片、按钮、题目、报告、字幕
    theme/                  # 配色、字体和运动参数
  scripts/                  # 渲染、混音、字幕与验证脚本
  previews/                 # 试音、关键帧和样片
  exports/                  # 正式 MP4、封面、字幕和音轨
  licenses/                 # 素材使用记录
```

### 8.3 时间轴与稳定渲染

所有运动由帧号或显式时间驱动。场景中的随机因素固定种子，避免不同渲染结果不一致。不依赖实时网站请求来播放动画，演示内容提前准备并保存在工程内。

45 秒、60 fps 对应 2700 帧。先用低分辨率快速预览，定稿后渲染正式分辨率。缓存静态素材、限制不必要的模糊层，兼顾画质与稳定性。

## 9. 执行步骤与阶段交付

| 阶段 | 实施内容 | 交付与检查 |
| --- | --- | --- |
| 1. 环境与素材准备 | 检查渲染工具、FFmpeg、字体、中文语音能力；提取品牌与界面元素；准备演示数据。 | 环境记录、素材清单、确定的制作路线。 |
| 2. 脚本与旁白定稿 | 落实每秒分镜，生成两版短试音，再完成整段旁白与时间轴。 | 试音、完整旁白、最终分镜时间表。 |
| 3. 关键样片 | 完成 10～12 秒“输入问题 → 点击生成 → 题目展开”，加入语音、音乐与音效。 | 可播放样片，检查配色、运动、文字与声音质感。 |
| 4. 全片动画 | 完成开场、答题、结果、分享及品牌收尾，加入字幕。 | 完整预览版，检查手机阅读与内容连贯性。 |
| 5. 精修与混音 | 调整转场、留白、停顿、音乐和音效，对齐字幕。 | 接近正式成片的版本及完整检查记录。 |
| 6. 正式渲染 | 导出正式视频与封面，检查编码、时长、音画同步与二维码。 | 正式 MP4、封面、SRT、音轨、工程与说明。 |

样片用于确认实际质感，不能只用静态图替代。样片如需调整，优先解决字体大小、运动连续性和旁白自然度，再扩展至全片。

## 10. 宣传封面

封面沿用奶油白背景，中间放一张紫色结果卡片，品牌清晰但不过大。主文案：

> **你的小小好奇，**  
> **值得一个答案。**

封面应有独立构图，不直接截取含大量小字的界面。使用与视频一致的字体、配色和卡片形态。裁剪到不同平台封面时，主标题和品牌仍应完整。

## 13. 制作边界与待确认项

本方案定稿后的工作范围是制作可上传的视频文件及配套素材。网络发布、选择发布账号和填写平台文案属于后续操作。

正式制作初期需要落实：中文语音工具与音色、品牌读法、背景音乐来源，以及具体演示测试。采用上述默认方向先推进，涉及外部付费服务时明确费用与使用条件。

视觉、配色、竖屏构图、连续卡片转场、中文旁白及不制作短版均已确定。最终成片要让观众自然理解：**有一个好奇的问题，就来测测be探索一下。**
