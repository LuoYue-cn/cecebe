## 2026-10-03：项目全面缺陷复核

在独立的 `cecebe_test` 数据库和 Redis `/1` 上复现并修复了以下问题，未改动业务数据库：

1. 安装向导“测试连接”和“完成安装”原共用一次/分钟的额度，第二步会被 429 阻断；改为按安装动作分别限流，并在已安装时先返回 409。未知安装动作返回 404。
2. 未启用可信代理时，所有访客原被视为同一 `local` IP，共用全站安装、账户和生成额度；改为对已校验的会话分别限流。账户操作按动作区分，登录后可立即退出。可信代理覆盖转发头时仍按客户端 IP 限流。
3. 分析失败后重新入队原复用 BullMQ 已失败任务 ID，可能无法真正执行；重试使用独立队列 ID，并在入队失败时恢复失败状态。
4. 公开报告读取原只检查测试处于已发布状态，未再次检查公开可见性；现有链接在测试切换为私密后立即失效。
5. 未完成分析的答卷原可通过 API 创建公开报告；现仅允许完整报告公开。知识测试的重复题干回顾改用题目 ID 查找选项，避免显示另一题的答案文本。
6. Schema 原允许知识/能力维度没有任何评分题，结果会出现凭空的 50 分；也允许倾向题携带标准答案。现两类结构都会被拒绝并交给 AI 修复流程。
