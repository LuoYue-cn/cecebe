## 限制与明确边界

- 测试 fixture 只位于 tests/，只由隔离 E2E 启动器运行，不是网站内置模拟 AI，不进入部署业务流程。
- 当前环境不能使用 Docker daemon，因此容器镜像实际构建与容器内健康检查需要部署环境复验。
- 没有提供真实 AI 密钥或 SMTP 账号，不声称已验证真实第三方模型生成质量、协议兼容性或邮件投递。
- 第一版 UI 为简体中文；测试题目支持四种语言选择，UI 文案目录为后续 i18n 留有入口。
- OAuth、自适应测试、双人测试、模板市场、Public API、结果模板缓存按方案作为后续扩展，未假装已开放。
- 所有核心功能免费，只有页脚广告；没有会员或付费解锁。
