# 制作记录

## 第一版成片

- 原生逐帧绘制并渲染 60 fps，1080×1920，时长 45.000 秒。
- H.264/yuv420p 视频与 AAC 48 kHz 立体声音轨；最终综合响度 -16.6 LUFS，真峰值 -1.5 dBFS。
- 7 条中文旁白和 7 条字幕对应 7 个分镜节点；最后一句在 42.06 秒结束，留约 2.94 秒品牌收尾。
- 原创合成氛围音乐、点击音、选择音、绽放音、轻柔转场音，已混音并保留独立音轨与混音母带。
- 二维码从最终视频 34 秒画面裁切后解码成功，目标为 `https://ccb.h666h.com`。
- 对最终 MP4 做完整 FFmpeg 解码，无解码错误；关键帧抽查开场、生成、答题、结果、分享与片尾。

## 发布前音色授权

普通话旁白由 Microsoft Edge TTS 的 `zh-CN-XiaoxiaoNeural` 合成，用于可试听的第一版。Microsoft 当前产品条款明确说明，Azure TTS 输出供商业用途的权利适用于 TTS 服务付费层客户；Edge Read Aloud 通道与 Azure 付费层的授权关系并未在本工程中确认。若视频作为测测be宣传片公开发布，应在发布前换为取得明确商用许可的配音或 TTS 音色，并更新旁白音频、字幕时间和混音。

## 真实页面修订版

- 以 `ccb.h666h.com` 的移动端真实首页、主题输入、测试说明、作答界面和结果页替换第一版的手绘假界面。
- 导出规格调整为 1080×1920、30 fps。使用固定画面和 0.6 秒缓和交叉溶解，移除原先逐帧缩放造成的轻微抖动。
- 字幕改为一行大字、简洁描边，不再加悬浮字幕卡；分享收尾回到真实首页，并将域名放到首页留白处。
- 结果页取自一条实际完成的公开计算机知识测试；答案全部正确，所以画面显示 100/100。为取得该真实结果页，公开完成数增加 1。其他页面录制脚本不会提交答卷。
- 重新合成第五句旁白为“看见你的知识版图，也看见下一步方向”，使内容对应实际展示的知识测试结果。
- 最终 MP4 经 FFmpeg 完整解码检查，1080×1920、30 fps、45 秒，含 AAC 48 kHz 双声道。
